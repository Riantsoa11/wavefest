# Glossaire

Une phrase métier par terme, sans mot technique.

## Glossaire WaveFest

| Terme | Définition |
|---|---|
| Édition | Une occurrence du festival WaveFest, à des dates données. |
| Organisateur | Équipe WaveFest qui fixe les règles de vente et fait tourner le festival. |
| Pass | Type de droit d'accès vendu : 1 jour, 3 jours ou VIP. |
| Pass VIP | Pass qui donne aussi accès au backstage et au bar dédié. |
| Billet | Exemplaire d'un pass acheté, au nom d'un titulaire. |
| Vague | Période de vente à prix fixe, close à sa date ou quand son quota est épuisé. |
| Quota | Nombre maximal de billets vendables dans une vague. |
| Commande | Achat de 1 à 6 billets par un acheteur, en un seul paiement. |
| Réservation | Blocage des places d'une commande non payée, pendant 15 minutes au plus. |
| Acheteur | Personne qui passe et paie une commande. |
| Titulaire | Personne dont le nom figure sur le billet ; elle seule peut entrer avec. |
| Festivalier | Titulaire présent sur le site, muni de son bracelet. |
| Changement de nom | Remplacement du titulaire d'un billet, gratuit jusqu'à J-7. |
| Revente | Vente d'un billet par son titulaire à un autre festivalier, via WaveFest. |
| Prix plafond | Prix maximal de revente, égal au prix d'achat du billet. |
| Commission de revente | Part de 5 % prélevée par WaveFest sur chaque revente. |
| Portique | Point d'entrée où le billet est échangé contre un bracelet. |
| Bracelet | Bracelet remis à l'entrée, propre à un seul festivalier, qui sert d'accès et de porte-monnaie. |
| Solde cashless | Argent disponible sur le bracelet pour payer sur le site. |
| Recharge | Ajout d'argent au solde cashless, en ligne ou sur place. |
| Consommation | Achat sur le site payé avec le solde cashless. |
| Remboursement du solde | Restitution du solde restant, jusqu'à 15 jours après le festival. |
| Frais de remboursement | Somme fixe de 1,50 € retenue sur un remboursement du solde. |
| Tête d'affiche | Artiste principal d'une journée ; son annulation ouvre droit à un remboursement partiel. |
| Annulation | Décision officielle qu'un concert prévu n'aura pas lieu. |
| PSP | Prestataire externe qui encaisse et rembourse les paiements. |
| Concert | Passage d'un artiste sur une scène, à une date et un horaire donnés. |
| Line-up | Liste des artistes programmés pour une édition. |
| Vendeur | Titulaire qui met son billet en revente. |
| Racheteur | Festivalier qui achète un billet en revente et en devient le titulaire. |
| Annonce de revente | Mise en vente d'un billet par son titulaire, au prix plafond au plus. |
| Campagne de remboursement | Ensemble des remboursements ouverts pour une journée dont la tête d'affiche est annulée. |
| Remboursement partiel | Restitution de 50 % du prix payé d'un pass 1 jour quand la tête d'affiche de la journée est annulée. |
| Grille des prix | Prix et places disponibles de la vague ouverte, consultés par l'acheteur. |
| Prestataire e-mail | Prestataire externe qui envoie les e-mails aux acheteurs et titulaires. |
| Bénévole au portique | Personne qui vérifie les billets et remet les bracelets à l'entrée. |
| Barman | Personne qui encaisse les consommations sur le site. |

## Un même mot, un sens par contexte (TP2)

| Mot | Billetterie | Revente officielle | Contrôle d'accès | Cashless | Remboursements |
|---|---|---|---|---|---|
| Billet | Exemplaire d'un pass, au nom d'un titulaire, avec un prix payé. | Objet d'une annonce, vendu au prix plafond. | QR à scanner, valide ou non. | N'existe pas : on parle de bracelet. | Ligne à rembourser : un titulaire et un montant. |
| Prix | Prix de la vague. | Prix plafond = prix d'achat. | Non utilisé. | Non utilisé. | Prix payé par le titulaire actuel. |
| Remboursement | Paiement tardif remboursé. | Non utilisé. | Non utilisé. | Remboursement du solde (J+15, 1,50 € de frais). | Remboursement partiel d'un pass (50 %). |

## Synonymes tranchés

On choisit un seul mot et on écarte les autres. Ces mots ne doivent plus apparaître dans le code ni dans les échanges.

| On dit | On ne dit pas |
|---|---|
| Pass | Formule, offre |
| Billet | Ticket, place, e-ticket |
| Vague | Phase, palier |
| Quota | Stock, contingent |
| Commande | Panier |
| Réservation | Hold |
| Acheteur | Client |
| Titulaire | Porteur, bénéficiaire |
| Festivalier | Visiteur, participant, utilisateur |
| Changement de nom | Transfert |
| Revente | Bourse |
| Commission de revente | Frais de revente |
| Portique | Entrée, contrôle |
| Bracelet | Puce, badge, RFID, wristband |
| Solde cashless | Crédit, porte-monnaie, cagnotte |
| Recharge | Top-up |
| Consommation | Transaction |
| Remboursement du solde | Rétrocession |
| Tête d'affiche | Headliner |
| Annulation | Déprogrammation |
| Organisateur | Admin, back-office |
| PSP | Banque, plateforme de paiement |
| Prestataire e-mail | SaaS e-mailing |
| Organisateur (pour annuler un concert) | Programmateur |
